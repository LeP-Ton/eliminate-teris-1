+# Eliminate Teris 1
+
+把消除游戏搬进 MacBook Touch Bar 的一次认真尝试。
+
+`Eliminate Teris 1` 是一款为 macOS 与 Touch Bar 场景设计的轻量消除游戏：战场不在大屏幕中央，而是在键盘上方那条熟悉又常被忽视的细长区域里。你会在 16 格的一维棋盘上交换相邻方块、制造三连消除、追逐更高分数，也会在竞速与限时模式里，把每一次操作都压缩成更紧凑、更直接的节奏。
+
+它的规则很直白，上手很快；但真正玩起来时，你会发现这一条窄窄的 Touch Bar，依然能装下判断、节奏、手感和一点点“再来一把”的执念。
+
+## 游戏特色
+
+### 1. 真正以 Touch Bar 为主战场
+- 游戏核心交互直接发生在 Touch Bar 上，而不是把 Touch Bar 当成附属按钮区。
+- 16 个可交互格子会实时显示棋盘状态，交换、消除、补位、动画与音效都围绕这块区域展开。
+- 对于带 Touch Bar 的 MacBook 来说，这不是“支持一下 Touch Bar”，而是“把 Touch Bar 变成游戏本体”。
+
+### 2. 一维消除，简单但不单调
+- 棋盘为横向 `16` 列。
+- 你只能交换相邻方块。
+- 连成 `3` 个及以上相同方块即可消除。
+- 被消除的每个方块计 `10` 分。
+- 消除后会从左侧补入新方块，棋盘重新形成新的节奏与机会。
+
+和传统二维三消不同，这种一维结构让判断路径更纯粹：少了复杂视线切换，多了对“下一步会不会连锁”的快速预判。每次交换都更像一次明确的出手。
+
+### 3. 三种模式，照顾练手、冲分与竞速
+- **自由模式**：没有时间限制，也没有目标分数，适合熟悉规则、放松手感。
+- **竞分模式**：在限定时间内尽可能拿高分，当前支持 `1 / 2 / 3` 分钟三个档位。
+- **竞速模式**：以最短时间冲到目标分数，当前支持 `300 / 600 / 900` 分三个目标。
+
+### 4. 本地挑战记录，记住每一次更强的自己
+- 游戏会按模式与细分规则分别保存挑战记录。
+- 例如“竞分 1 分钟”和“竞分 3 分钟”会分开排行；“竞速 300 分”和“竞速 900 分”也各自独立。
+- 每个记录桶最多保留 `9` 条成绩，方便持续追分、反复刷新个人最佳。
+
+### 5. 有节奏感的视听反馈
+- 不同模式对应不同的程序化 BGM（背景音乐）。
+- 交换、消除、补位分别拥有独立音效。
+- 音频在运行时合成，不依赖额外音频资源文件，整体风格更轻、更干净，也更适合这个项目的实验气质。
+
+### 6. 多语言支持
+- 游戏当前支持 `简体中文`、`English`、`日本語`、`한국어`、`Русский` 五种语言。
+- 这不仅是界面翻译，也是在尝试让这款小而特别的游戏更容易被不同玩家理解和进入。
+
+## 怎么玩
+
+### 基础目标
+通过交换相邻方块，让相同颜色的方块连成至少 3 个，触发消除并获得分数。
+
+### 操作方式
+- **Touch Bar 点按**：先选中一个方块，再点按相邻方块进行交换。
+- **Touch Bar 拖动**：从一个方块滑向左右相邻方块，直接完成交换。
+- **多点触控**：支持多根手指同时参与操作，适合更快节奏下的连续判断。
+
+### 计分方式
+- 每个被消除的方块固定计 `10` 分。
+- 连续消除会继续累计得分。
+- 竞分模式按最终分数排名；竞速模式按达成目标分数所用时间排名。
+
+## 模式说明
+
+### 自由模式
+适合第一次接触本作时进入。它没有时间压力，不要求你立刻跑出一套最优思路，而是让你先感受一维棋盘、Touch Bar 手感，以及消除节奏是如何建立起来的。
+
+### 竞分模式
+这是最直接的“冲高分”玩法。你要在有限时间里尽量制造更多有效交换，让分数尽快抬升。它更考验稳定输出、连续判断和临场节奏。
+
+### 竞速模式
+竞速模式把目标改成“尽快到达指定分数”。当目标是 `300` 分、`600` 分或 `900` 分时，你需要的不只是正确操作，还包括尽可能少的犹豫与停顿。它更像是一场短跑。
+
+## 游戏界面说明
+
+除了 Touch Bar 主棋盘外，桌面窗口还提供了完整的辅助信息区域：
+
+- **游戏设置**：切换模式、规则档位、语言，并开始或重新开始一局。
+- **时间与得分**：显示当前用时、剩余时间（如适用）与得分变化。
+- **挑战记录**：按当前模式与细分规则展示本地最佳记录。
+- **玩法说明**：根据当前模式展示对应规则，帮助玩家快速理解本局目标。
+
+也就是说，这个项目不是“只有一条 Touch Bar 在工作”，而是把窗口信息面板和 Touch Bar 主战场组合成了一套完整的游玩体验。
+
+## 运行环境
+
+### 面向玩家
+- macOS `12.0` 或更高版本
+- 一台带 **Touch Bar** 的 MacBook Pro（核心体验强依赖 Touch Bar）
+
+### 面向开发者
+- Xcode 与 Swift 开发环境
+- 可用的命令行工具（`swift`、`codesign`、`hdiutil` 等）
+
+> 如果你的设备没有 Touch Bar，应用仍可能启动，但将无法完整体验这款游戏的核心玩法。
+
+## 快速开始
+
+### 1. 本地运行
+项目根目录提供了启动脚本：
+
+```bash
+./run.sh
+```
+
+这个脚本会在启动前自动重新编译，避免误启动旧的构建产物。执行流程大致如下：
+
+1. 自动定位 Xcode Developer 目录（如果你没有手动设置 `DEVELOPER_DIR`）
+2. 执行 `swift build --disable-sandbox`
+3. 自动解析可执行文件输出目录
+4. 启动 `Eliminate Teris 1`
+
+### 2. 打包成可分发应用
+如果你想生成 `.app`、`.dmg` 或 `.zip`，可以使用：
+
+```bash
+./package.sh
+```
+
+打包脚本会：
+- 分别构建 `x86_64` 与 `arm64` 版本
+- 通过 `lipo` 合成为通用二进制
+- 自动拷贝 SwiftPM 资源 Bundle
+- 写入 `Info.plist`
+- 执行 ad-hoc 签名
+- 优先输出 `.dmg`，若当前环境不支持则自动回退为 `.zip`
+
+默认产物位于：
+
+```bash
+dist/
+```
+
+如果你只想打某一种架构，也可以覆盖环境变量：
+
+```bash
+PACKAGE_ARCHS=\"arm64\" ./package.sh
+```
+
+## 项目结构速览
+
+```text
+.
+├── Sources/
+│   ├── AppDelegate.swift
+│   ├── GameViewController.swift
+│   ├── GameTouchBarView.swift
+│   ├── GameState.swift
+│   ├── GameAudioSystem.swift
+│   ├── ModeRecordStore.swift
+│   └── Resources/
+├── run.sh
+├── package.sh
+└── Package.swift
+```
+
+几个关键文件的职责可以这样理解：
+
+- `Sources/GameTouchBarView.swift`：Touch Bar 棋盘渲染、触控交互、动画表现
+- `Sources/GameState.swift`：棋盘状态、匹配判定、消除与左侧补位逻辑
+- `Sources/GameViewController.swift`：桌面窗口 UI、模式切换、状态展示
+- `Sources/ModeRecordStore.swift`：本地挑战记录的分桶保存与排序
+- `Sources/GameAudioSystem.swift`：程序化 BGM 与交互音效
+- `Sources/Localization.swift`：多语言资源查找与切换
+
+## 为什么这个项目有意思
+
+很多 Touch Bar 软件，要么把它当快捷键容器，要么把它当附属显示条；而 `Eliminate Teris 1` 更像是在回答一个更具体的问题：
+
+**如果 Touch Bar 不是配角，而是主舞台，会发生什么？**
+
+这个项目给出的答案是：
+- 可以做出真正可玩的游戏；
+- 可以拥有足够明确的反馈与节奏；
+- 可以在很小的空间里，依旧留下策略与挑战；
+- 也可以让一块常被忽略的硬件，重新变得有趣。
+
+## 已知说明
+
+- 当前正式方案优先采用公开 Touch Bar 路径，以保证开发态与打包版的稳定显示。
+- 不同 macOS 版本、不同机型下，Touch Bar 的可见宽度与系统保留区域可能略有差异。
+- 本项目当前更适合作为一款面向 Touch Bar MacBook 的特色作品与实验型游戏，而不是面向所有 Mac 的通用休闲游戏。
+
+## 适合谁
+
+如果你属于下面任意一种人，这个项目大概率会让你会心一笑：
+
+- 你还在使用带 Touch Bar 的 MacBook，并且一直想看看它还能不能更“像个设备”而不是“像个配件”
+- 你喜欢规则简单、节奏清楚、可以随时来一局的小型游戏
+- 你对 macOS 原生开发、Touch Bar 交互或非常规 UI 载体感兴趣
+- 你想研究“公开 API + SwiftPM + 手工打包”的一套轻量原生项目结构
+
+## 最后
+
+`Eliminate Teris 1` 不是一款追求庞大内容量的游戏，它更像一个方向明确、个性鲜明的小作品：把消除的满足感、Touch Bar 的特殊性、以及一点点像素街机气质，压缩进一条狭长却足够有趣的交互空间里。
+
+如果你也喜欢这种“不大，但认真”的东西，欢迎运行它、改它、继续把它做得更好。

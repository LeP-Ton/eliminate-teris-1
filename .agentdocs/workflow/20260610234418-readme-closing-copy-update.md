# README 结尾邀请文案调整

## 背景与目标
- 当前中文 `README.md` 结尾使用的是“欢迎运行它、改它、继续把它做得更好”的表达，整体更偏开源协作语气。
- 本次目标是把这句收束文案改得更轻一点、更像对外展示页结尾，调整为“如果你也喜欢这种‘不大，但有趣’的东西，欢迎关注并留言。”

## 约束与原则
- 仅调整中文 README 的这句结尾文案，不扩散修改其他段落。
- 英文 README 本次不联动改写，避免超出用户当前需求。
- 同步更新索引与项目认知，确保后续可追溯。

## 关键风险
- 如果顺手联动改英文 README，容易超出当前明确需求，因此本次只改中文版本。
- 如果不更新索引和认知，后续再追查 README 文案演变时会缺少记录。

## 当前进展
- 中文 README 结尾文案已从“运行它、改它、继续把它做得更好”改为“欢迎关注并留言”。
- 新文案保留了“小而特别”的项目气质，但整体情绪更轻、更适合项目介绍页收尾。
